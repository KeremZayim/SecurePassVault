# 🔐 SecurePassVault

**SecurePassVault**, AES-256 tabanlı güvenli şifre yönetimi için geliştirilmiş, JavaFX tabanlı masaüstü bir uygulamadır.  
Tüm parolalar yerel olarak şifreli biçimde saklanır, internet bağlantısı gerekmez.

---

## 🚀 Özellikler
- AES-256 şifreleme ile güvenli veri saklama
- Master password doğrulama
- Parola ekleme, düzenleme, silme
- Otomatik clipboard temizleme
- Şifreli JSON yedekleme
- Güçlü parola üretici
- JavaFX tabanlı modern arayüz

---

## 🧩 Teknolojiler
- Java 17+
- JavaFX
- SQLite (JDBC)
- Gson
- AES-256 Encryption
- JUnit 5
